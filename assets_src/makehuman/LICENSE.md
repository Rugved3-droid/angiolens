# MakeHuman base mesh: CC0

`base.obj` is the MakeHuman base mesh, downloaded from
https://raw.githubusercontent.com/makehumancommunity/makehuman/master/makehuman/data/3dobjs/base.obj

Its header states: "This asset was explicitly released as CC0 in september 2020." The MakeHuman FAQ
(static.makehumancommunity.org/oldsite/faq/what_changed_regarding_the_license_in_2020.html) says that
"targets, proxies and the base mesh are considered graphical assets, covered by CC0".
Only the `body` group is used (preprocess/scripts/build_body.py). Fit to the patient is approximate.
